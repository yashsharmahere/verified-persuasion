Verified Persuasion

A conversation system that tries to change one person's mind about one wrong belief, and may only say what it can trace to a named source. If it can't source a claim, it doesn't say it.

Try the demo

The demo uses a made-up belief and a stand-in for the AI model, so you can click through every page a participant sees. It doesn't use the AI model or the study's database.

The conversation Talk to the system. Every sentence it sends has passed the source check, and names its source. The brochure The comparison condition: the same verified quotes, as a fixed page, with no conversation.

Each ends with the 0–100 belief questions a participant answers.

How it works

  1. Draft. A model writes a reply, using only passages a person has checked against the original source.
  2. Split. A separate model call breaks the reply into pieces and labels each one: a factual claim, a question, or a reflection. Anything it can't label counts as a claim.
  3. Check. Each factual claim is tested against its passage: does the passage actually say this, not just talk about the same topic?
  4. Send or refuse. Only a reply whose every claim passes is sent, with its sources named. Otherwise the model redrafts, and if it still fails, the system says it can't back that up.

What gets measured

The participant rates the belief from 0 to 100 before anything else, after reading the brochure, after the conversation, and again seven days later. If the brochure moves the belief as much as the conversation does, the conversation added nothing, and the study says so. Every claim the system drafts is logged, including the ones it blocked, so the share of unsupported claims that got through can be counted. That share should be zero.
